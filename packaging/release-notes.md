Discover songs on YouTube and SoundCloud, create your library and playlists, and customize your sound with a seven-band equalizer.

- **Windows:** download the `windows-x64-setup.exe` installer and run it. A portable ZIP is also available. Requires Microsoft Edge WebView2 Runtime.
- **Linux:** download the `linux-x64.tar.gz` package, extract it and run `bash install.sh` inside the extracted folder. Voxen appears in your application menu. Requires WebKitGTK 4.1 and a working audio device. On Arch: `sudo pacman -S --needed webkit2gtk-4.1`. On Ubuntu: `sudo apt install libwebkit2gtk-4.1-0`.

Packages include .NET, FFmpeg and SDL3. Library data stays in your user profile. Verify downloads against `SHA256SUMS.txt`. These initial Windows packages are unsigned.
